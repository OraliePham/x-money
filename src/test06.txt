================================================================================
                    HƯỚNG DẪN PHÁT TRIỂN TÍNH NĂNG
                    READ TWEET FOLLOW - LẤY USER TỪ COMMENT
================================================================================

MỤC ĐÍCH: Lấy thông tin các user đã comment vào tweet, đặc biệt là các user
         có verified (xác minh), và lưu vào database để quản lý.

================================================================================
1. MÔ TẢ TÍNH NĂNG
================================================================================

Tính năng "readTweetFollow" dùng để:
- Đọc tất cả comments/replies của một tweet
- Trích xuất thông tin user đã comment (username, display name, avatar, stats)
- Phát hiện user có verified (blue, gold, grey)
- Lưu thông tin vào database SQLite
- Tùy chọn tự động follow các verified user

================================================================================
2. CẤU TRÚC DỮ LIỆU LƯU TRỮ
================================================================================

2.1. Bảng comment_users trong SQLite:

┌─────────────────────┬─────────────┬────────────────────────────────────────┐
│ Tên cột             │ Kiểu dữ liệu│ Mô tả                                  │
├─────────────────────┼─────────────┼────────────────────────────────────────┤
│ id                  │ TEXT(PK)    │ Khóa chính: {profile_id}_{user_id}     │
│ profile_id          │ TEXT(FK)    │ ID của profile đã đọc comment          │

│ is_verified         │ INTEGER     │ 0/1 - Có blue verified không           │
│ is_gold_verified    │ INTEGER     │ 0/1 - Có gold verified không           │
│ is_grey_verified    │ INTEGER     │ 0/1 - Có grey verified không           │
│ followers_count     │ INTEGER     │ Số lượng followers                      │
│ following_count     │ INTEGER     │ Số lượng following                      │
│ tweet_count         │ INTEGER     │ Tổng số tweets                         │
│ bio                 │ TEXT        │ Tiểu sử user                            │
│ location            │ TEXT        │ Vị trí địa lý                           │
│ avatar_url          │ TEXT        │ URL avatar                              │
│ comment_text        │ TEXT        │ Nội dung comment                        │
│ comment_timestamp   │ TEXT        │ Thời gian comment (ISO)                 │
│ comment_url         │ TEXT        │ Link đến comment cụ thể                │
│ status              │ TEXT        │ pending/followed/skipped/blocked       │
│ is_followed         │ INTEGER     │ 0/1 - Đã follow hay chưa                │
│ followed_at         │ DATETIME    │ Thời điểm follow                        │
│ up_time             │ DATETIME    │ Thời gian tạo record                    │
└─────────────────────┴─────────────┴────────────────────────────────────────┘

2.2. Các chỉ mục (Indexes) cần tạo:

- idx_comment_users_profile_id: Tìm kiếm theo profile_id
- idx_comment_users_username: Tìm kiếm theo username
- idx_comment_users_status: Lọc theo trạng thái
- idx_comment_users_up_time: Sắp xếp theo thời gian

================================================================================
3. LUỒNG XỬ LÝ CỦA HÀM readTweetFollow
================================================================================

BƯỚC 1: Kiểm tra trang hiện tại
─────────────────────────────────────────────────────────────────────────────
- Xác nhận đang ở trang tweet detail (URL chứa '/status/')
- Nếu không, báo lỗi và thoát

BƯỚC 2: Load comments
─────────────────────────────────────────────────────────────────────────────
- Scroll để load thêm comments (tối đa N lần)
- Mỗi lần scroll chờ 1.5-2 giây
- Dừng khi không còn comments mới

BƯỚC 3: Trích xuất thông tin user
─────────────────────────────────────────────────────────────────────────────
- Lấy tất cả article[data-testid="tweet"]
- Bỏ qua tweet đầu tiên (tweet gốc)
- Duyệt qua từng reply và trích xuất:
  • Username và display name
  • Verification status (blue/gold/grey)
  • Nội dung comment
  • Thời gian comment
  • Avatar URL
  • Follower counts (nếu có)

BƯỚC 4: Lọc verified users
─────────────────────────────────────────────────────────────────────────────
- Chỉ giữ lại user có is_verified = true
- (Tùy chọn) Có thể lấy tất cả user

BƯỚC 5: Lưu vào database
─────────────────────────────────────────────────────────────────────────────
- Ghi thông tin vào bảng comment_users
- Cập nhật nếu đã tồn tại (INSERT OR REPLACE)

BƯỚC 6: (Tùy chọn) Auto-follow
─────────────────────────────────────────────────────────────────────────────
- Nếu bật flag followVerifiedUsers
- Tự động follow từng verified user
- Random delay giữa các lần follow (1.5-3 giây)
- Cập nhật status và is_followed trong database

8. CÁC LỆNH SỬ DỤNG MẪU
================================================================================

8.1. Đọc comments từ tweet cụ thể:
─────────────────────────────────────────────────────────────────────────────
npx tsx src/profile-launcher.ts profile_01_id https://x.com/username/status/123456789 --read-comments

8.2. Đọc comments và tự động follow verified users:
─────────────────────────────────────────────────────────────────────────────

8.3. Đọc comments với số lượng tối đa 100:
─────────────────────────────────────────────────────────────────────────────

8.4. Kết hợp nhiều tính năng (like, follow author, đọc comments):
─────────────────────────────────────────────────────────────────────────────

8.5. Chỉ đọc comments từ tweet đang mở trong browser:
─────────────────────────────────────────────────────────────────────────────

9. CẤU TRÚC DỮ LIỆU ĐẦU RA (CommentUserInfo)
================================================================================

{
  id: string;                    // User ID
  username: string;              // Username (không có @)
  displayName: string;           // Tên hiển thị
  isVerified: boolean;           // Có verified không
  isGoldVerified: boolean;       // Gold verified (tổ chức)
  isGreyVerified: boolean;       // Grey verified (chính phủ)
  followersCount: number;        // Số followers
  followingCount: number;        // Số following
  tweetCount: number;            // Số tweets
  bio?: string;                  // Tiểu sử
  location?: string;             // Vị trí
  avatarUrl?: string;            // URL avatar
  commentText: string;           // Nội dung comment
  commentTimestamp: string;      // Thời gian comment
  commentUrl: string;            // Link đến comment
  isFollowing: boolean;          // Profile hiện tại có follow user này không?
  status: 'pending' | 'followed' | 'skipped' | 'blocked';
  upTime: Date;                  // Thời gian tạo record
}

10. CÁC TRUY VẤN SQL HỮU ÍCH
================================================================================

10.1. Xem danh sách verified users đã lưu:
─────────────────────────────────────────────────────────────────────────────
SELECT username, display_name, followers_count, status, up_time 
FROM comment_users 
WHERE is_verified = 1 
ORDER BY up_time DESC 
LIMIT 20;

10.2. Xem các user đã được follow:
─────────────────────────────────────────────────────────────────────────────
SELECT username, display_name, followed_at 
FROM comment_users 
WHERE is_followed = 1 
ORDER BY followed_at DESC;

10.3. Thống kê số lượng user theo trạng thái:
─────────────────────────────────────────────────────────────────────────────
SELECT status, COUNT(*) as count 
FROM comment_users 
GROUP BY status;

10.4. Tìm user theo username:
─────────────────────────────────────────────────────────────────────────────
SELECT * FROM comment_users WHERE username LIKE '%keyword%';

10.5. Xóa các user cũ (quá 30 ngày):
─────────────────────────────────────────────────────────────────────────────
DELETE FROM comment_users WHERE up_time < datetime('now', '-30 days');
